
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes or improvements.
4. Commit your changes with a clear commit message.
5. Push your changes to your fork.
6. Submit a pull request.

## Reporting Bugs

If you find a bug, please open an issue and provide a clear description of the problem.

## Suggestions and Enhancements

Suggestions, new ideas, and enhancements that can improve the Simple Interest Calculator are welcome.

Thank you for contributing to this project.
