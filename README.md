 Simple Interest Calculator

This project provides a simple Bash script that calculates simple interest based on user-provided values.

## Description

The Simple Interest Calculator allows users to enter:

- Principal amount
- Rate of interest
- Time period

The calculator uses the following formula:

Simple Interest = (Principal × Rate × Time) / 100

This project is part of an initiative to transition from SVN to Git and make the project available to the open-source community.

## Usage

Run the `simple-interest.sh` script and follow the prompts to enter the principal, rate of interest, and time period.
